# Trading Gateway Service

FastAPI-шлюз, предоставляющий REST/WebSocket интерфейс для управления торговой платформой. Текущая реализация включает:

- подключение к базе данных (по умолчанию SQLite) с SQLAlchemy-моделями пользователей, стратегий и инструментов;
- сидинг демо-данных (админ-пользователь, торговые пары Binance, две стратегии с привязкой к инструментам);
- CRUD-эндпоинты для стратегий и инструментов, работающие с реальной БД;
- базовую аутентификацию с проверкой пароля и OTP (через TOTP);
- агрегацию дашборда на основе данных из хранилища.

## Быстрый старт

```bash
cd services/gateway
uvicorn app.main:app --reload
```

При первом запуске будет создан файл `gateway.db` в корне сервиса. Настройки переопределяются переменными окружения `GATEWAY_*` (см. `app/core/config.py`).

### Пример окружения

```
GATEWAY_DATABASE_URL=sqlite:///./gateway.db
GATEWAY_SECRET_KEY=super-secret
GATEWAY_FIRST_SUPERUSER_EMAIL=admin@example.com
GATEWAY_FIRST_SUPERUSER_PASSWORD=admin
```

## Структура

- `app/main.py` — создание приложения, инициализация БД и регистрация роутеров.
- `app/core/` — конфигурация и утилиты безопасности.
- `app/db/` — SQLAlchemy-модели, сессия и сидинг данных.
- `app/crud/` — слой доступа к данным для стратегий и инструментов.
- `app/api/` — реализации REST-маршрутов.
- `app/schemas.py` — Pydantic-схемы запросов/ответов.
